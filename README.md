# GLOSS Detailing Studio

Landing page for an auto detailing studio in Moscow. Services, pricing, portfolio, testimonials, FAQ, map and a contact form.

React 19 · TypeScript · Vite · Tailwind CSS · Framer Motion · Radix UI

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build      # output to dist/
npm run preview    # serve the build locally
```

## Docker

```bash
docker compose up --build   # http://localhost:8080
```

## Content

Studio details (brand, contacts, address, hours, map links) live in `src/config.ts`.
